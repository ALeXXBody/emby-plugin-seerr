Seerr Requests

Link your Seerr (Overseerr/Jellyseerr) instance. Users open Requests in the Emby sidebar/menu, or /emby/Seerr/Ui as a standalone page.

Base URL of your Seerr server.
Seerr → Settings → General → API Key.
Comma-separated Emby user names. Empty = every logged-in user. Enforced on all /Seerr API calls.
Security: requests are created in Seerr as the API-key owner (not the Emby user). Prefer a least-privilege Seerr key. Seerr URL must be http(s); loopback/link-local/metadata hosts are blocked.
